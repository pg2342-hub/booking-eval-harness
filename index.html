Booking Eval Harness

A runnable 25-case eval for an AI booking agent at a home services contractor. It checks that every AI-booked job lands with the right job type, fee, service area and slot, and that the agent hands off the calls it should never book.

Why the gate exists

A booking counts as a win even when a detail is wrong: a plan member quoted the $95 standard fee instead of the $49 member fee is still a "booking." This harness defines what a correct booking is for one contractor, and the gate an agent must pass before it books on its own.

The reference agent reads structured facts, not the raw transcript, so its 25 of 25 shows the checks can be written as code and the grader agrees with a correct policy. It is not a claim about a model. The naive agent shows what the grader catches. A live-model adapter is included but has not been run.

Does every check get caught?

An eval set that still passes with a check switched off is not testing that check. The reference agent runs again with one check off at a time; an outlined square is a call that caught it.

Hand-off rule offcaught by 22, 24, 25

The job and area checks are caught by only two calls each, the thinnest coverage and the first place to add cases. With the slot check off, the agent takes the first open window, which is the emergency window, so almost every routine booking fails.

When a check is unsure

Book and flag

A CSR can fix it before the technician leaves.

  • A lapsed membership
  • An unclear job type
  • An unconfirmed promotion

Do not book, hand off

It cannot be fixed later.

  • An out-of-area address
  • A gas smell
  • A commercial job
  • A billing dispute

Stopping a booking costs the job, especially after hours; booking the wrong one costs a truck roll or a safety risk.

Data

Constructed test calls, not real customer data. The $49 and $95 fees come from a contractor's public Home Protection Plan page; everything else is invented.

Run it yourself

Python 3.9+, standard library only.

python3 run_eval.py --agent spec --runs 3
python3 run_eval.py --agent naive --runs 3
